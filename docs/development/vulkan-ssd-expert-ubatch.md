# Vulkan SSD 专家缓存 `-ub` 修改说明

作者：Coffee <544103252@qq.com>

来源提交：`44552b9a0997389d49d694608cd1d213d639b4da`

## 修改内容

本次修改解决了 `-ub` 只能设置为 1 的问题。根本原因是 `mapped_topk_tensor` 等数组中代表 token 数量的维度此前硬编码为 `1`，现在改为使用实际的 `n-tokens`，并根据当前 token 数量动态调整相关缓冲区和张量布局。

prefill 阶段输入多个 token 时，单次路由所需的专家数量可能超过缓存池内可用的专家数量。因此当前实现会根据缓存池大小和 top-K 专家数限制单次处理的最大 `-ub` 数，以避免一次 microbatch 请求超过专家缓存容量。

目前存在一个问题：prefill 阶段输入多个 token 时用到的专家数量可能 > 缓存池内可用的专家数量，目前实现方法为根据缓存池大小和 top-K 专家数限制单次处理的最大 `-ub` 数，但不是最终方案。

后续应继续优化多 token prefill 的专家缓存管理和淘汰策略，减少对 `-ub` 的限制。
